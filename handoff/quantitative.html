Quantitative Tests

New in August 2026 and not yet designed: quantitative test types (Afla M1) no longer run the confirmation flow and never show Positive, Negative, or Inconclusive. The flow always ends after the first test, there is no result popup, and the reader shows the measured concentration instead, formatted against the test type's measurable range (Afla M1: 15-150): readings below range show as < 15, in-range readings show the number, readings above range show as > 150, always prefixed with CONC. The violet in these captures is a prototype placeholder - the final design needs a dedicated neutral color for quantitative results, for example gray or a light blue clearly distinct from the cyan already used for controls. Red positive, green negative, amber inconclusive, and cyan control colors keep their current meanings.

Dashboard Results

When a quantitative read finishes, no result popup is shown - the concentration appears directly on the channel card in the neutral completed state, and View Details opens the flow detail.

2 states

Concentration levels on the dashboard

Ports 1-3 show completed Afla M1 tests in the three display forms: below range (CONC < 15), in range (CONC 65), and above range (CONC > 150). Port 4 shows a completed qualitative negative test for color contrast.

Flow detail: quantitative

View Details for a completed quantitative test. The summary badge and the single contained test both show the concentration, and the substance row shows only the measured value - no ratio and no Positive or Negative label.

History

Quantitative records reuse the neutral color in the history list, flow detail, and test detail, and show the concentration wherever qualitative tests show Positive or Negative. Substance rows show only the measured concentration - the substance ratio and per-substance result labels belong to qualitative tests only.

3 states

History list with quantitative rows

Test records list mixing quantitative and qualitative flows. Quantitative rows use the neutral color and their sequence chip shows the concentration instead of a result word.

History flow detail: quantitative

Flow detail for a quantitative record: the flow result is the concentration, the sequence chip carries the value, and the flow always contains exactly one test.

History test detail: quantitative

Individual test detail for a quantitative record with the measured concentration and the light intensity curve. The substance row shows the value only.

Insert Warning

Not specific to quantitative tests, but new: inserting a cassette while another inserted cassette has not been configured and started yet raises a warning popup, because the waiting cassette is already developing in the warm reader.

1 states

Insert warning popup

Port 1 holds an inserted cassette that was never configured and started; inserting a second cassette into port 2 raises the warning telling the operator to start the previous cassette first.
